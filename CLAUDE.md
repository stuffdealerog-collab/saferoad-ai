# SafeRoad AI — инструкции для Claude Code

Превентивная аналитика дорожной безопасности: детекция почти-аварий (near-miss) по видео
с существующих камер, чтобы находить опасные участки **до** того, как там произойдёт ДТП.

Канонический контекст проекта — `docs/TECH_PLAN_v2.md`. Бизнес-контекст — `docs/BUSINESS_STRATEGY.md`.
Если ответ на вопрос есть в техплане, он важнее любых догадок по коду.

## Роль

Работай как независимый технический партнёр, а не как исполнитель. Если видишь плохое
допущение — скажи прямо. Не соглашайся ради согласия. Ошибка, найденная сейчас, дешевле
ошибки, найденной на демонстрации в министерстве.

При ревью чужого кода используй уровни: **CRITICAL / HIGH / MEDIUM / LOW**.

## Непреложные инварианты

Их нельзя нарушать без явного обсуждения. Каждый из них появился из конкретного риска.

1. **Вся математика безопасности — детерминированная и проверяемая.** TTC, PET, скорости,
   дистанции считает обычный код с юнит-тестами. Языковая модель не принимает решений о
   безопасности и не участвует в вычислении метрик — только в текстах отчётов.
2. **Время берётся только из PTS**, восстановленных на этапе ingest. Никогда
   `frame_idx / fps` — это молча ломается на видео с переменным фреймрейтом.
3. **Разрывы больше `max_gap_s` разрывают трек.** Никакой тихой интерполяции: лучше два
   честных сегмента, чем один придуманный.
4. **Пиксели и метры не смешиваются.** Суффиксы обязательны: `_px`, `_m`, `_s`, `_mps`.
   Переменная без единицы измерения в имени — это баг.
5. **Пороги живут в версионированных профилях** (`configs/thresholds/`) и помечены как
   экспериментальные, пока не пройдут валидацию на размеченном экспертами «золотом наборе»
   (Milestone 8). Каждый прогон записывает в манифест, каким профилем он посчитан.
6. **Оценка риска — индекс приоритизации, а не вероятность аварии.** Никогда не описывай
   её как вероятность, ни в коде, ни в комментариях, ни в интерфейсе.
7. **Техническая точность детекции ≠ доказанная связь с будущими ДТП.** Это разные
   утверждения, и их нельзя подменять одно другим в отчётах и презентациях.
8. **Никакого распознавания лиц и номеров.** Ни в коде, ни в зависимостях, ни в планах.
   Хранятся траектории и метаданные, а не персональные данные.
9. **Каждое событие объяснимо.** Reason codes плюс сырые метрики, по которым инженер может
   восстановить и опровергнуть любой вывод. Событий без объяснения не бывает.
10. **Событие никогда не создаётся одним порогом.** «TTC < X» сам по себе не near-miss:
    нужен набор сигналов с прозрачными весами.

## Как устроен код

Стадийный конвейер, каждая стадия сериализует артефакт и пишет манифест прогона:

```
ingest/      восстановление PTS, квалификация видео (отказ с явной причиной)
vision/      детектор, гейт качества треков, калибровка/гомография, рендер, клипы-доказательства
motion/      фильтр Калмана + RTS-сглаживание в плоскости дороги
geometry/    зоны конфликта
safety/      ttc, pet, парный анализ конфликтов, классификация near-miss
pipeline/    оркестрация прогона
apps/api     FastAPI, apps/web — дашборд
landing/     публичный сайт и интерактивная симуляция метода
```

## Команды

```bash
python -m pytest -q                      # 72 теста, все должны проходить
python -m pipeline.run --synthetic       # прогон на синтетике с известной истиной
python -m http.server 8000 -d landing    # симуляция: /simulation.html
node docs/pitch_deck_build.js            # пересборка презентации
```

## Правила работы с этим репозиторием

- Тесты должны проходить перед каждым коммитом. Падающий тест — это не «потом поправим».
- Синтетический прогон — регрессионный тест физики: PET пешеход↔машина = 0.375 с,
  ровно одно событие near-miss, ноль фантомных торможений на равномерном движении.
- Видео для браузера кодируется **H.264** (`core/video_utils.to_h264`). OpenCV пишет mp4v,
  который Chrome и Safari не проигрывают — на демонстрации это чёрный прямоугольник.
- Не добавляй зависимости без причины: систему разворачивают в госучреждении, где каждый
  пакет проходит проверку.
- Не выдумывай метрики точности. Пока нет валидации на золотом наборе, честный ответ —
  «не измерено».
