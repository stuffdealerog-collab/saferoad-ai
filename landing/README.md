# SafeRoad AI — лендинг

Одностраничный сайт-визитка проекта. Три языка (RU / UZ / EN), без сборки —
только `index.html` и два скриншота продукта.

## Локально
```bash
python3 -m http.server 8080     # из этой папки → http://localhost:8080
```

## Публикация

**Vercel (CLI, 2 команды):**
```bash
npx vercel          # первый запуск: вход через браузер, затем Enter на все вопросы
npx vercel --prod   # получить постоянный адрес *.vercel.app
```

**Без установки чего-либо:** app.netlify.com/drop — перетащить эту папку в окно
браузера, ссылка выдаётся сразу.

Содержимое (статистика, контакты, дорожная карта) правится прямо в `index.html`:
русские тексты лежат в разметке, переводы UZ/EN — в объекте `T` внизу файла.
